One original line roasting the gadget I use every day — my power bank, which
got my phone to 3% and quit, like a personal trainer who only shows up for
the warm-up.

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (101 characters,
inside the 200-character gate).
